# LemmaDuck mascot family

All three editions share the yellow voxel rubber duck, two visible eyes, chalk,
and a proof slate reading `LEMMA` and `P ⇒ Q`. The README shows each at 176px.

| Asset | Distro | Distinguishing cue |
| --- | --- | --- |
| `lemmaduck.webp` | Base | Original proof duck |
| `lemmaduck-emacs.png` | Emacs | Purple beret with `(λ)` |
| `lemmaduck-neovim.png` | Neovim | Emerald cap with `:w` |

The variants were made with OpenAI ImageGen by editing the existing base image.
Generated PNGs retain their original transparency. They are local README assets,
so rendering does not depend on an external image host.

## Variant prompts

Preserve the original cheerful yellow voxel duck, two visible square eyes, orange
beak, chalk and proof slate. Keep `LEMMA` and `P ⇒ Q` on separate lines. Use a
transparent background and a readable 176px composition. Emacs adds a purple
scholar beret with `(λ)` and an aubergine slate. Neovim adds an emerald cap with
`:w` and a forest-green slate. Keep yellow dominant and both eyes unobstructed.
